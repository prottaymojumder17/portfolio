📝 How to Update Content
All content is stored in the data/ folder as JSON files. To update content:

Edit the JSON file (e.g., data/publications.json to add a new paper)

Save the file

Commit and push:

git add .
git commit -m "Add new publication"
git push

GitHub Pages will automatically rebuild the site in 1-2 minutes.

Adding a New Publication
Edit data/publications.json:

{
"type": "Journal",
"text": "Author names. Paper title.",
"journal": "Journal Name",
"journalLink": "https://doi.org/...",
"volume": "Volume(Issue), pages",
"citation": "[X citations]",
"conference": "Conference info (optional)",
"bibtex": "@article{...}"
}

Adding a New Project
Edit data/projects.json:

{
"title": "Project Title",
"description": "Short description",
"icon": "code-outline",
"category": "dl",
"tags": ["Python", "PyTorch"],
"link": "https://github.com/..."
}
